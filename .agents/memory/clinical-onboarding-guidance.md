Write the user guide for someone unfamiliar with the system who starts with no patient data: every patient must be registered/imported and then enrolled. Document everything that comes out of the box.

**Why:** The owner said, “The idea is clinician etc does least amount of work to manage patients not the system.”

**How to apply:** Separate one-time administrator/operator setup from daily clinical care. Explain what is automated versus what requires a clinical decision, consent or signature. An empty-practice documentation scenario is not permission to clear an existing database.
